Запуск

1

Запустите Docker Desktop и дождитесь полной загрузки (1-2 мин)

2

Откройте PowerShell и запустите контейнеры:

cd C:\edu-rag-portable docker-compose -f docker-compose-portable.yml up -d
3

Откройте в браузере: http://localhost:5678

2

Демонстрация

☁️ Онлайн — GPT-5-nano

Ответ за 3-5 секунд
"llm": "gpt"
Рекомендуется для демо

🔒 Оффлайн — DeepSeek R1

Ответ за 1-3 минуты
"llm": "local", "top_k": 1
Proof of concept

Примеры запросов через PowerShell (workflow должен быть Active):

# Онлайн (GPT) — биология на русском Invoke-WebRequest -Uri "http://localhost:5678/webhook/edu-rag-query" ` -Method POST -ContentType "application/json; charset=utf-8" ` -Body ([System.Text.Encoding]::UTF8.GetBytes( '{"question":"Что такое фотосинтез?","llm":"gpt","subject":"biology"}' ))
# Оффлайн (Ollama) — на английском Invoke-WebRequest -Uri "http://localhost:5678/webhook/edu-rag-query" ` -Method POST -ContentType "application/json; charset=utf-8" ` -Body ([System.Text.Encoding]::UTF8.GetBytes( '{"question":"What is a cell?","llm":"local","subject":"biology","top_k":1}' ))
ПараметрЗначениеОписание
questionлюбой текстВопрос (обязательный)
llmgpt / localОнлайн или оффлайн
subjectbiology, english…Фильтр по предмету
grade7 – 12Фильтр по классу
top_k1 – 3Чанков контекста (local ≤ 2)

💡 Советы для демо

  • Для быстрого показа используйте gpt — ответ мгновенный
  • Русский, английский, румынский — язык определяется автоматически
  • Для оффлайн-режима всегда передавайте top_k: 1
⚙

3

Завершение работы

1

Выполните в PowerShell:

cd C:\edu-rag-portable docker-compose -f docker-compose-portable.yml down

⛔ Не потеряйте данные!

  • docker-compose down -v — флаг -v удалит ВСЕ данные
  • docker rm -f — может пересоздать volumes
  • docker volume rm — удалит данные безвозвратно
